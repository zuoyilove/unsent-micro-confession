One unsent micro-confession: a To: line naming who it was meant for, and the message itself, one line written exactly as it was typed, with no explanation after it. It stayed in drafts because saying it out loud would have meant admitting how much it was needed.

## Run it

```sh
node main.ts
```

The program writes the two-part confession to `/output/entry.txt`.
